Computer Vision

CCTV 기반 낙석 탐지

YOLOv8 객체 탐지와 프레임 차분 기반 움직임 검출을 결합해 낙석 후보를 필터링하는 연구 프로토타입을 구현했습니다.

상세 내용
문제 정의

낙석 탐지는 작은 물체가 빠르게 움직이고, 조명 변화나 배경 흔들림으로 오탐이 쉽게 발생하는 영상 문제였습니다. 이를 줄이기 위해 YOLOv8 단독 탐지 결과를 그대로 사용하지 않고, 프레임 간 차분으로 실제 움직임이 발생한 영역을 함께 추출했습니다.

구현 방식

영상 프레임을 순차 처리하면서 YOLOv8로 암석 후보 박스를 만들고, OpenCV 기반 MotionDetector로 움직임 박스를 계산했습니다. 두 박스가 IoU/IoM 기준을 만족하는 경우만 최종 낙석 후보로 남기고, GUI에서 confidence, iou threshold, 타일 크기, step, 표시 방식(box/dot/none)을 조정할 수 있도록 구성했습니다.

실험 방향

이미지 크기, batch size, learning rate 조합을 바꿔가며 YOLOv8 학습 실험을 진행했고, 작은 낙석을 놓치지 않는 recall 중심 설정과 오탐을 줄이는 precision 중심 설정 사이의 trade-off를 확인했습니다.

구현 기록: YOLOv8·MotionDetector 코드, IoU/IoM fusion, GUI 기반 영상 처리 흐름.

Anomaly Detection

터널 MWD 이상 탐지

터널 시공 현장의 MWD 신호와 RMR 변화 데이터를 연결해 지반 위험 구간을 추정하고 비지도 이상 탐지 모델을 비교했습니다.

상세 내용
문제 정의

터널 굴진 중 장비에서 수집되는 boring speed, rotation pressure, feed pressure 등의 MWD 신호가 지반 상태 변화를 간접적으로 반영한다는 점에서 출발했습니다. 원본 현장 데이터를 깊이 기준으로 정렬하고, RMR 값이 저하되는 구간을 위험 구간의 proxy label로 정의했습니다.

모델 비교

Isolation Forest, Local Outlier Factor, One-Class SVM을 비교했고, feature 조합과 contamination, n_neighbors, gamma, nu 같은 모델 파라미터를 바꿔가며 실험했습니다. 탐지 결과는 해석 가능한 위험 구간으로 만들기 위해 가까운 이상 구간을 병합하고, 너무 짧은 구간은 필터링했습니다.

평가 방식

예측 위험 구간과 RMR 저하 구간을 0.5m depth-bin 단위로 비교해 Precision, Recall, F1 Score, Accuracy, OMC를 산출했습니다. 이 과정을 통해 현장별로 안정적인 feature 조합과 모델을 확인했습니다.

구현 기록: IF/LOF/OCSVM 실험 GUI, depth-bin 평가, 결과 CSV와 시각화 그래프.
